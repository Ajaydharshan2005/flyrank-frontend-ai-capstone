# FlyRank Frontend AI Capstone

An AI-powered frontend application developed for the FlyRank Frontend AI Engineering track. This repository documents the project from initial setup through the development of an accessible, responsive, and maintainable frontend experience.

## Project Status

**Current milestone:** FE-04 — Capstone Skeleton, Deployed

The application has a Next.js App Router structure, placeholder pages, shared global styling, and a health-check page that fetches and displays data.

The specific application features and AI capabilities will be defined and developed incrementally in later milestones.

## Technology Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- HTML and CSS
- Git and GitHub
- Vercel deployment
- AI-assisted development

## Current Routes

- `/` — Home
- `/dashboard` — Dashboard placeholder
- `/query` — Query placeholder
- `/documents` — Documents placeholder
- `/history` — History placeholder
- `/settings` — Settings placeholder
- `/health` — Health-check page

## Development Approach

The project will be developed incrementally throughout the FlyRank Frontend AI Engineering track.

AI coding assistants will be used for development, code review, debugging, documentation, and improving implementation quality.

## Development Principles

- Responsive layouts
- Maintainable code
- Responsible use of AI-assisted development
- Clear error handling and reliable data presentation
